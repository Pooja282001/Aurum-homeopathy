# 📋 QUICK REFERENCE - SEPARATE SCREENS & MENU

## 🎯 THE THREE SCREENS

### **1️⃣ 📊 DASHBOARD SCREEN**
```
🟢 System Status      ⚙️ Maintenance Mode
```
- **Primary Purpose**: System control & monitoring
- **Main Controls**:
  - Toggle Online/Offline
  - Enable/Disable Maintenance Mode
- **Info Displayed**:
  - System status (ONLINE/OFFLINE)
  - Maintenance Mode state
  - Total Users count
  - Total Appointments count

### **2️⃣ 📋 APPOINTMENTS SCREEN**
```
[➕ Create New Appointment]

[New]  Patient Name · Phone · Date · Time
       [Edit]  [Delete]
```
- **Primary Purpose**: Manage all appointments
- **Main Actions**:
  - Create new appointments
  - Edit appointment details
  - Delete appointments
  - View appointment status

### **3️⃣ 👥 USERS SCREEN**
```
[➕ Create New User]
```

- **Primary Purpose**: Manage all users
- **Main Actions**:
  - Create new users
  - Edit user information
  - Change user passwords
  - Disable/Delete users

## 🎮 HOW TO SWITCH SCREENS

### **Step 1: Look at the Menu**
```
[📊 Dashboard]  [📋 Appointments]  [👥 Users]
```

### **Step 2: Click Your Target Screen**
- Red button = Currently active
- Gray buttons = Available to click

### **Step 3: Screen Updates Instantly**
- Content changes immediately
- Menu button turns red
- Other buttons turn gray

## 🎨 MENU BUTTON STATES

### **Active State (Current Screen)**
```
[BUTTON] - Red background, white text
```
Example: `[📊 Dashboard]` when on Dashboard screen

### **Inactive State (Other Screens)**
```
[BUTTON] - Gray background, black text
```
Example: `[📋 Appointments]` when not on Appointments screen

### **Hover State**
```
[BUTTON] - Slight color change, slight lift effect
```
Provides visual feedback before clicking

## 🆘 TROUBLESHOOTING

### **Problem: Menu not visible**
- **Solution**: Scroll to top of dashboard page

### **Problem: Can't switch screens**
- **Solution**: Reload page (F5) and try again

### **Problem: Wrong content showing**
- **Solution**: Click the correct menu button - button should turn red

### **Problem: Buttons not working**
- **Solution**: Check if you have correct permissions (must be Super Admin)
